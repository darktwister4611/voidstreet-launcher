# Void Street Launcher

Descarga **VoidStreetLauncher.exe** de la [última versión](../../releases/latest) y ábrelo.

- La primera vez pregunta con qué juegas: **CurseForge** o **SKLauncher / launcher oficial** (`.minecraft`). Se cambia en *Ajustes*.
- **Actualizar** pone tu perfil al día: baja solo lo que falta (de CurseForge o de aquí), aparta lo viejo en `mods_quitados_void_street` sin borrar nada y no toca tus ajustes ni tus mods propios.
- Con `.minecraft` instala Forge 1.20.1-47.4.10 si falta.
- Cierra Minecraft antes de actualizar. Windows puede avisar porque el .exe no está firmado: *Más información → Ejecutar de todas formas*.
